# Запуск скрипта

## 1. Установка зависимостей (Перед запуском убедитесь, что у вас установлен Python 3.10+)
```bash
pip install -r requirements.txt
````
## 2. Заполнить креды
Создайте файл `.env` и укажите в нём необходимые параметры:


## 3. Загрузить переменные окружения

```bash
set -o allexport
source path_to_env
```
Где `path_to_env` — путь к вашему `.env` файлу.

## 4. Запуск скрипта
```bash
python main.py
```
